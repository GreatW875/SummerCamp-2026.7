## 一、基本概念

### 监督学习 vs 无监督学习

| 维度 | 监督学习 (Supervised) | 无监督学习 (Unsupervised) |
|------|----------------------|--------------------------|
| **前提条件** | ① 有明确要预测的目标 ② 有带标签的历史数据（X + y） ③ 标签获取成本可接受 | ① 想发现数据结构/模式，无预设答案 ② 没有标签，或标签获取成本极高 ③ 想做探索性分析 |
| **数据** | 有标签（特征 X + 目标 y） | 无标签（只有特征 X） |
| **目标** | 学习 X -> y 的映射关系 | 发现数据内在结构/模式 |
| **典型任务** | 分类（y离散）、回归（y连续） | 聚类、降维、异常检测 |
| **例子** | 房价预测、垃圾邮件识别 | 客户分群、PCA降维 |

> **记忆口诀**：监督学习有"老师"（标签当答案），无监督学习没"老师"（自己找规律）。

### 训练集与测试集

```
全部数据
┌──────────────────────────────────┐
│         训练集 (70%~80%)           │  -> 训练模型（学习参数）
│  ┌────────────────────────────┐  │
│  │  验证集 (从训练集中划出)     │  │  -> 调超参数、选模型
│  └────────────────────────────┘  │
├──────────────────────────────────┤
│         测试集 (20%~30%)           │  -> 最终评估，只用一次
└──────────────────────────────────┘
```

| 集合 | 作用 | 类比 |
|------|------|------|
| **训练集** | 模型从中学习参数（$w$, $b$） | 平时作业 |
| **验证集** | 调超参数、选模型（不参与训练，可反复使用） | 模拟考试 |
| **测试集** | 最终验证泛化能力（只用一次，不参与任何调参） | 期末考试 |

> **为什么必须划分？** 测试集代表"没见过的新数据"，衡量模型的**泛化能力**。用训练数据评估模型相当于"拿作业当考试"，无法检验真实水平。
>
> **验证集 vs 测试集的关键区别**：验证集可以反复用来试不同超参数；测试集只能用一次。如果反复用测试集调参，它就退化成了第二个验证集，失去衡量泛化能力的意义。

### 参数 vs 超参数

| 类型 | 含义 | 谁决定 | 例子 |
|------|------|--------|------|
| **参数（Parameter）** | 模型从数据中学到的 | 模型自己学 | 线性回归的 $w$ 和 $b$、神经网络的权重 |
| **超参数（Hyperparameter）** | 训练前人为设定的 | 人决定 | 学习率 $\eta$、正则化系数 $\lambda$、树的深度、KNN的K值 |

> **一句话区分**：模型自己学的是**参数**，你手动设的是**超参数**。训练集学参数，验证集调超参数，两者分工明确。

### 过拟合、欠拟合

| 概念 | 现象 | 原因 | 解决方案 |
|------|------|------|----------|
| **欠拟合** | 训练集和测试集表现都差 | 模型太简单 / 特征太少 | 增加模型复杂度、增加特征 |
| **过拟合** | 训练集极好，测试集差 | 模型太复杂 / 记住了噪声 | 正则化、增加数据、降复杂度 |
| **泛化能力** | 对未见数据的预测能力 | -- | 最终追求的目标 |

> **过拟合的本质**：模型把训练数据中的**噪声和偶然规律**也当成了真实规律。就像学生背下了往年考试每道题，换一套新题就不会了。

**缓解过拟合的常见手段**：
1. 增加数据量
2. 正则化（L1/L2）
3. 降低模型复杂度
4. 交叉验证
5. 早停（Early Stopping）

### 正则化（L1 / L2）

**核心思想**：模型过拟合时权重 $w$ 往往过大。正则化在损失函数中加一个惩罚项 $R(w)$，逼 $w$ 保持小，从而限制模型复杂度。

$$L_{总} = L_{数据} + \lambda \cdot R(w)$$

- $L_{数据}$：原始损失（MSE 或交叉熵）
- $R(w)$：正则化项（惩罚 $w$ 的大小）
- $\lambda$：正则化系数（控制惩罚力度，越大越约束）

| 类型 | $R(w)$ 公式 | 惩罚方式 | 效果 |
|------|------------|---------|------|
| **L1（Lasso）** | $\sum_{j} \|w_j\|$ | 权重绝对值之和 | 产生稀疏解（很多 $w_j=0$），自动做特征选择 |
| **L2（Ridge）** | $\sum_{j} w_j^2$ | 权重平方和 | 整体压小 $w$（不为0），平滑稳定，通用首选 |

> **为什么 L1 产生稀疏解？** L1 的约束区域是菱形，尖角朝向坐标轴，等高线碰角就使某个 $w_j=0$；L2 是圆形，无角，只能整体压小。

## 二、损失函数

> **核心目标：让损失函数最小。** 损失函数衡量模型预测值与真实值之间的差距，差距越小，模型越好。

### 均方误差（MSE）-- 回归任务最常用（监督学习）

$$L = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$

- $n$：样本数量
- $\hat{y}_i$：第 i 个样本的预测值
- $y_i$：第 i 个样本的真实值

**为什么用平方？**
- 对大误差惩罚更大（鼓励模型不要犯大错）
- 平方函数处处可导，便于梯度计算
- 统计意义：误差服从正态分布时，最小化MSE等价于最大似然估计

### 交叉熵损失（Cross-Entropy）-- 分类任务最常用（监督学习）

$$L = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]$$

- $y_i \in \{0, 1\}$：真实标签
- $\hat{y}_i$：预测概率（Sigmoid 输出）
- $n$：样本数

| 真实标签 | 起作用的项 | 预测对时 | 预测错时 |
|---------|-----------|---------|---------|
| $y=1$ | $-\log(\hat{y})$ | $\hat{y}\to1$，损失$\to0$ | $\hat{y}\to0$，损失$\to\infty$ |
| $y=0$ | $-\log(1-\hat{y})$ | $\hat{y}\to0$，损失$\to0$ | $\hat{y}\to1$，损失$\to\infty$ |

> **直觉**：预测对了几乎不惩罚，"自信地预测错"狠狠惩罚。

**为什么分类不用 MSE？** Sigmoid + MSE 是非凸函数，有多个局部最小值，梯度下降找不到全局最优。交叉熵 + Sigmoid 是凸函数。

## 三、核心算法

### 线性回归（监督学习）

#### 模型公式

$$\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{w}^\top \mathbf{x} + b$$

- $\mathbf{x}$：输入特征向量
- $\mathbf{w}$：权重（每个特征的重要性）
- $b$：偏置（截距）
- $\hat{y}$：预测值

> 目标：找到一组 $\mathbf{w}$ 和 $b$，使损失 $L$（MSE）最小。

#### 梯度下降

> **直觉**：站在山上，看不见全貌，只能感受脚下坡度。沿着最陡的下坡方向走一步，逐步走到谷底（损失最小）。

**更新公式**：

$$w \leftarrow w - \eta \cdot \frac{\partial L}{\partial w}$$

$$b \leftarrow b - \eta \cdot \frac{\partial L}{\partial b}$$

- $\eta$：学习率，控制每步走多大
- $\frac{\partial L}{\partial w}$、$\frac{\partial L}{\partial b}$：梯度，指向损失上升最快的方向，加负号 = 下降最快

#### 梯度公式推导

对 $L = \frac{1}{n} \sum (\hat{y}_i - y_i)^2$ 用链式法则求偏导：

```
L = (ŷ - y)²        ← 外层：平方
     ↑
ŷ = w·x + b          ← 内层：线性组合

∂L/∂w = ∂L/∂ŷ × ∂ŷ/∂w = 2(ŷ-y) × x
∂L/∂b = ∂L/∂ŷ × ∂ŷ/∂b = 2(ŷ-y) × 1
```

对所有 n 个样本求和并取平均：

$$\frac{\partial L}{\partial w} = \frac{2}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i) \cdot x_i$$

$$\frac{\partial L}{\partial b} = \frac{2}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)$$

| 偏导 | 公式 | 直觉 |
|------|------|------|
| ∂L/∂w | $\frac{2}{n} \sum (\hat{y}_i - y_i) \cdot x_i$ | 误差乘以输入：$x_i$ 越大，该样本对 $w$ 的修正贡献越大 |
| ∂L/∂b | $\frac{2}{n} \sum (\hat{y}_i - y_i)$ | 只和误差有关：$b$ 是全局偏移，所有样本误差平均后直接调 |

> **为什么 ∂L/∂w 多了一个 $x_i$？** 因为 $w$ 乘在 $x_i$ 上（$w \cdot x_i$），求导时 $x_i$ 留了下来；而 $b$ 是单独加的（$+b$），求导后系数为 1。

#### 学习率的影响

| 学习率 | 现象 | 后果 |
|--------|------|------|
| **太大** | 步子太大，跨过谷底到对面 | 震荡或发散，无法收敛 |
| **太小** | 步子太小，每次几乎不动 | 收敛极慢 |
| **适中** | 稳定下降，逐步逼近最小值 | 理想状态 |

#### 梯度下降的代码实现

```python
import numpy as np

# 数据准备
X = np.array([[1, 2], [2, 3], [3, 4], [4, 5]])  # (n, 2) 4个样本, 2个特征
y = np.array([3, 5, 7, 9])                        # (n,) 真实值
n = len(y)

# 初始化参数
w = np.zeros(X.shape[1])  # (2,) 权重初始化为0
b = 0.0                    # 偏置初始化为0
lr = 0.01                  # 学习率
epochs = 1000              # 迭代次数

# 训练循环
for epoch in range(epochs):
    # 前向传播：计算预测值
    y_hat = X @ w + b               # (n,) = (n,2)@(2,) + 标量

    # 计算梯度
    dw = (2 / n) * np.sum((y_hat - y) * X, axis=0)   # (2,) 每个特征一个梯度
    db = (2 / n) * np.sum(y_hat - y)                  # 标量

    # 更新参数
    w = w - lr * dw
    b = b - lr * db

    # 每100轮打印一次损失
    if epoch % 100 == 0:
        loss = np.mean((y_hat - y) ** 2)
        print(f"Epoch {epoch}, Loss: {loss:.4f}")
```

**梯度代码详解**：

| 代码 | 对应公式 | 说明 |
|------|---------|------|
| `y_hat = X @ w + b` | $\hat{y} = \mathbf{w}^\top \mathbf{x} + b$ | 矩阵乘法一次性算所有样本的预测值 |
| `y_hat - y` | $(\hat{y}_i - y_i)$ | 预测值与真实值的误差，shape `(n,)` |
| `np.sum((y_hat - y) * X, axis=0)` | $\sum (\hat{y}_i - y_i) \cdot x_i$ | 误差乘以输入再按列求和，shape `(2,)` |
| `np.sum(y_hat - y)` | $\sum (\hat{y}_i - y_i)$ | 误差求和，标量 |
| `2 / n` | $\frac{2}{n}$ | 求平均 |

> **关键**：`(y_hat - y) * X` 利用了 NumPy 广播机制--`(n,)` 误差乘以 `(n, 2)` 输入，误差自动扩展到每列，再 `axis=0` 求和得到每个特征的梯度。

### 逻辑回归（监督学习）

#### 为什么线性回归不能做分类？

线性回归输出任意实数（$-\infty$ 到 $+\infty$），但分类需要概率（0 到 1）。解决方案：在线性回归外面套一层 **Sigmoid**，把实数压缩到 $(0,1)$。

#### Sigmoid 函数

$$\sigma(z) = \frac{1}{1 + e^{-z}}, \quad z = \mathbf{w}^\top \mathbf{x} + b$$

```
σ(z)
1 │              ___________   ← z 大 -> σ->1（预测正类）
  │           ╱
0.5│───────╱─────────────────  ← z=0 -> σ=0.5（决策边界）
  │     ╱
0 │__╱________________________  ← z 小 -> σ->0（预测负类）
```

#### 模型公式

$$\hat{y} = \sigma(\mathbf{w}^\top \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^\top \mathbf{x} + b)}}$$

> 本质：线性回归算分 -> Sigmoid 把分转成概率 -> $\hat{y} > 0.5$ 判为正类。

#### 损失函数：交叉熵

$$L = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]$$

> **为什么不用 MSE？** Sigmoid + MSE 是非凸函数，有多个局部最小值。交叉熵 + Sigmoid 是凸函数，梯度下降能找到全局最优。

#### 梯度公式

$$\frac{\partial L}{\partial w} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i) \cdot x_i$$

$$\frac{\partial L}{\partial b} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)$$

> 和线性回归梯度形式几乎一样，只是 $\hat{y}$ 从 $w \cdot x + b$ 变成了 $\sigma(w \cdot x + b)$。交叉熵 + Sigmoid 的梯度恰好消掉了 Sigmoid 的导数项，非常简洁。

#### 梯度下降的代码实现

```python
import numpy as np

# 数据准备
X = np.array([[1, 2], [2, 3], [3, 4], [4, 5]])  # (n, 2)
y = np.array([0, 0, 1, 1])                        # (n,) 二分类标签
n = len(y)

# 初始化参数
w = np.zeros(X.shape[1])
b = 0.0
lr = 0.1
epochs = 1000

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# 训练循环
for epoch in range(epochs):
    # 前向传播
    y_hat = sigmoid(X @ w + b)            # (n,) 概率

    # 计算梯度（交叉熵 + Sigmoid）
    dw = (1 / n) * np.sum((y_hat - y) * X, axis=0)   # (2,)
    db = (1 / n) * np.sum(y_hat - y)                  # 标量

    # 更新参数
    w = w - lr * dw
    b = b - lr * db

    if epoch % 100 == 0:
        loss = -np.mean(y * np.log(y_hat + 1e-8) + (1 - y) * np.log(1 - y_hat + 1e-8))
        print(f"Epoch {epoch}, Loss: {loss:.4f}")
```

> **注意**：`np.log` 内加 `1e-8` 防止 $\hat{y}=0$ 或 $1$ 时 $\log(0)=-\infty$ 导致 NaN。

### 线性回归（监督学习） vs 逻辑回归对比

| 维度 | 线性回归 | 逻辑回归 |
|------|---------|---------|
| **任务** | 回归（y连续） | 分类（y离散） |
| **模型** | $\hat{y} = \mathbf{w}^\top \mathbf{x} + b$ | $\hat{y} = \sigma(\mathbf{w}^\top \mathbf{x} + b)$ |
| **输出** | 任意实数 | $(0, 1)$ 概率 |
| **损失函数** | MSE：$\frac{1}{n}\sum(\hat{y}-y)^2$ | 交叉熵：$-\frac{1}{n}\sum[y\log\hat{y}+(1-y)\log(1-\hat{y})]$ |
| **梯度** | $\frac{2}{n}\sum(\hat{y}-y) \cdot x$ | $\frac{1}{n}\sum(\hat{y}-y) \cdot x$ |
| **决策方式** | 直接输出值 | $\hat{y} > 0.5$ 判为正类 |
| **正则化** | L1/L2 均可 | L1/L2 均可（sklearn 默认 L2） |
