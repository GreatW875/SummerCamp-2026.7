## 二、机器学习知识全景地图 

> 用法：每学完一个阶段，回到这张地图，把已掌握的条目勾掉。地图上标注了各条目归属的学习阶段（S1–S5）。

### 1. 基础设施层

- **数学基础**（核心应用场景，S1）
  - **微积分**：梯度下降及变体、凸优化问题、LogSumExp 技巧（数值稳定性）。
  - **线性代数**：矩阵分解（SVD 用于推荐）、特征值分解（PCA 核心）、张量运算。
  - **概率统计**：假设检验（A/B 测试）、最大似然估计（MLE）、贝叶斯先验。
  - **信息论**：KL 散度、交叉熵、互信息（用于特征选择）。
- **编程工具栈**
  - **核心**：NumPy（矩阵运算）、Pandas（数据处理）、Scikit-Learn（算法引擎）。
  - **可视化**：Matplotlib（基础）、Seaborn（统计）、Plotly（交互式）。
  - **工程化**：Joblib / ONNX（模型序列化）、Optuna（超参数优化）、MLflow（实验追踪）。（S4–S5）

### 2. 数据处理层（S3）

- **EDA（探索性数据分析）**：
  - 分布分析（直方图 / QQ 图）、相关性分析、缺失值模式分析。
- **特征工程**：
  - **清洗**：异常值处理（3σ 原则 / IQR）、缺失值插补（均值 / KNN / MICE）。
  - **编码**：
    - One-hot Encoding（低基数类别）；
    - Target Encoding（高基数类别，如邮编、ID，防止维度爆炸；**必须配合交叉验证防泄漏**）；
    - Frequency / Count Encoding（处理类别出现频率）；Ordinal Encoding（有序类别）。
  - **变换**：归一化 / 标准化、Box-Cox / Yeo-Johnson（处理非正态分布）、对数变换。
  - **特征选择**：
    - Filter 法：方差阈值、相关系数、卡方检验、互信息；
    - Wrapper 法：递归特征消除（RFE）；
    - Embedded 法：L1 正则化、树模型重要性。
  - **高级**：分箱、特征交互、时序特征（Lag 特征、滑动窗口统计）。
- **Pipeline 化（补充）**：用 sklearn 的 `Pipeline` + `ColumnTransformer` 把预处理串成管道——这是防止数据泄漏、保证训练/测试一致性的标准做法。

### 3. 核心算法层

- **线性模型**（S1）：
  - 线性回归（最小二乘法）、逻辑回归（Sigmoid + 交叉熵）。
  - 泊松回归（计数预测，如客流量）。
  - 正则化：L1 / Lasso、L2 / Ridge、ElasticNet。
- **树模型**（S2）：
  - 决策树（CART、基尼系数 / 信息增益）。
  - **集成学习（重中之重）**：
    - Bagging：随机森林（降低方差）；
    - Boosting：GBDT → XGBoost（正则化 / 稀疏感知）→ LightGBM（直方图 / Leaf-wise）→ CatBoost（自动处理类别特征）；
    - Blending / Stacking（模型融合）。
- **距离与密度**（S1–S2）：
  - KNN（KD-Tree 加速）。
  - 聚类：K-Means（K 值选择 / 手肘法 / 轮廓系数）、DBSCAN（密度聚类，识别噪声点）、层次聚类。
  - 异常检测：孤立森林、One-Class SVM。
- **核方法**（S1）：SVM（支持向量机、核技巧）。
- **降维**（S2）：PCA（线性）、t-SNE / UMAP（非线性流形学习，用于可视化）。

### 4. 模型评估与诊断层（S4）

- **评估指标**：
  - 回归：MSE、MAE、RMSE、R²、RMSLE。
  - 分类：**混淆矩阵**、Accuracy、Precision、Recall、F1、**ROC-AUC**、**PR-AUC**（不平衡数据首选）、LogLoss、KS 值（风控常用）。
  - 排序：NDCG、MRR（推荐 / 搜索常用）。
- **类别不平衡专题（补充）**：为什么不平衡数据下 Accuracy 会骗人；重采样（SMOTE / 欠采样）、Class Weight、阈值移动。
- **验证方法**：
  - 留出法、K-Fold CV（分层采样 StratifiedKFold）、TimeSeriesSplit（时间序列防穿越）、GroupKFold（同组样本不跨折）。
- **模型诊断**：
  - 学习曲线：判断高偏差（欠拟合）还是高方差（过拟合）；
  - 验证曲线：观察单一超参数对性能的影响。
- **概率校准**：Platt Scaling、Isotonic Regression（让输出的概率是"真概率"，风控必备）。

### 5. 模型解释层（S4–S5）

- **全局解释**：特征重要性、Permutation Importance（置换重要性）、Partial Dependence Plot（PDP）。
- **局部解释**：SHAP Values（沙普利值，当前最主流）、LIME。

### 6. 工程与部署层（S5）

- **模型持久化**：Pickle、Joblib、ONNX（跨语言部署）。
- **服务化**：FastAPI / Flask 封装 REST API；Docker 容器化。
- **监控**：数据漂移监控、模型性能衰减监控（概念入门即可）。

## 四、进阶学习方法 

1. **公式反向推导法**：看到损失函数，试着自己推参数更新公式。例：逻辑回归的 Loss 为 L = −[y·log(ŷ) + (1−y)·log(1−ŷ)]，尝试对 w 求偏导，再和教材对照。**数学一般的同学：第二遍学的时候再做这一步，第一遍先建直觉。**
2. **代码复现法**：在用 `sklearn.fit()` 之前，先用 NumPy 手写核心算法（KNN、决策树分裂、K-Means）。这能让你深刻理解矩阵维度的变化——Shape mismatch 是新手最常见的坑。
3. **对比实验法（控制变量）**：固定模型改预处理，或固定预处理改模型。例：固定数据集，对比"标准化 vs 不标准化"对 LR 和 RF 的影响——你会发现 LR 敏感、RF 不敏感，并理解原因。
4. **消融实验法**：去掉某个（组）特征，看性能下降多少，以此验证特征构造是否有效。这是特征工程阶段的核心习惯。
5. **错误分析法**：不要只看总分。专门挑出预测错误的样本人工归因：是特征缺失？数据噪声？还是类别边界本来就模糊？把结论写进实验报告。
6. **可视化思维**：高维数据画 PCA 投影，分类问题画决策边界，调参画验证曲线，解释模型画 SHAP 依赖图。一图胜千言，也是检查理解的最好方式。

## 五、练习与实战项目库

### 1. 玩具级（练基础流程）

- **Iris / Wine / Breast Cancer**（sklearn 内置）：
  - 任务：PCA 降维可视化；K-Means 聚类与轮廓系数评估；SVM 分类调参（C 和核函数）。

  - 任务：从 Name 提取 Title；家庭规模特征；Target Encoding 处理高基数类别；Stacking 融合。

### 3. 竞赛 / 工业级（练高阶技巧）

- **Default of Credit Card Clients（信用卡违约，UCI）**：
  - 任务：类别不平衡处理；特征选择；ROC 曲线与 KS 曲线；模型解释（为什么该客户被判违约）。
- **Porto Seguro's Safe Driver Prediction（Kaggle）**：
  - 任务：特殊缺失值处理（−1 视为单独类别）；特征交互；模型融合。

## 七、避坑指南 

1. **数据泄漏是第一大坑**：任何用了"全量数据"信息的预处理（如先标准化再划分训练/测试、Target Encoding 不做 K 折、时序数据随机打散），都会让离线分数虚高、上线翻车。对策：预处理一律放进 `Pipeline`，一切在交叉验证内部发生。
2. **不要上来就啃公式**：数学一般的同学先跑通代码建立直觉，第二遍再回头推导。顺序反了极易劝退。
3. **不要刷课不动手**：看 10 小时视频不如亲手写 1 小时代码。每节课后立刻复现，合上书能写出来才算会。
4. **不要盲目调参**：先画学习曲线判断欠拟合/过拟合，再决定是加数据、加特征还是调超参。调参是最后一步不是第一步。
5. **不平衡数据别看 Accuracy**：99% 正常的交易里全猜"正常"也有 99% 准确率。用 PR-AUC、F1、KS。
6. **随机种子要固定**：`random_state=42` 写进所有实验，否则结果无法复现、无法对比。
