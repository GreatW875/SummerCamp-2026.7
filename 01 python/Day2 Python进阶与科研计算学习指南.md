## 概念 1：科研工程生存包

**学习目标**：改掉“面条代码”习惯，建立环境隔离、路径管理与调试的工程规范。

**知识点**：

- 虚拟环境隔离原理
- 相对路径与绝对路径
- Python内存模型与陷阱
- 图形化调试技巧

- **虚拟环境**：使用 `venv` 或 `conda` 创建专属环境，导出 `requirements.txt`。
- **路径管理**：使用 `pathlib.Path` 库管理文件路径。
- **内存陷阱**：可变对象作为默认参数的坑；浅拷贝与深拷贝 (`copy.deepcopy`) 的区别。
- **调试技巧**：VS Code 断点调试（F5启动，F10单步跳过，F11单步进入），条件断点。

**练习**：

1. 创建一个新的虚拟环境并激活。
2. 编写一个脚本，使用 `pathlib.Path` 读取当前目录下 `data/` 文件夹中的任意CSV文件。
3. 故意制造一个除零错误，使用 VS Code 断点停在错误前，查看变量状态。
4. **内存陷阱验证**：编写一个函数 `def add_item(item, lst=[])`，连续调用两次 `add_item(1)`，打印结果并解释为什么列表没有被清空。将其修复为 `lst=None` 的正确形式。
5. **深浅拷贝对比**：创建一个嵌套列表 `a = [[1, 2], [3, 4]]`，分别用 `b = a.copy()` 和 `c = copy.deepcopy(a)` 复制，然后修改 `a[0][0] = 99`，观察并打印 `b` 和 `c` 的区别。

**任务**：配置好个人的科研开发环境，创建标准的项目文件夹结构（包含 `src/`, `data/`, `configs/`, `.gitignore`）。

**注意事项**：

- 严禁在代码中写死绝对路径（如 `D:/user/data.csv`），换电脑必报错。
- 不要在全局Python环境中装包，会导致依赖冲突无法复现。

## 概念 2：面向对象编程 (OOP)

**学习目标**：掌握OOP核心思想，能设计合理的类层次与接口，封装科研数据与操作。

**知识点**：

- 类与对象的关系
- 魔术方法与属性封装
- 组合与继承的选择

**子项**：

- **基础**：`__init__` 初始化，`self` 的含义。
- **科研神器**：`@dataclass`（Python 3.7+），用最少代码定义数据容器。
- **魔术方法**：`__str__`, `__repr__`, `__len__`。
- **封装**：`@property` 装饰器实现只读属性或带校验的赋值。
- **设计原则**：优先使用组合而非继承，降低代码耦合度。

**练习**：

1. 使用 `@dataclass` 定义一个 `SensorReading` 类，包含 `timestamp`, `value`, `is_valid` (默认True)。
2. 给 `SensorReading` 添加一个 `@property` 方法，返回 `value` 的平方。
3. **魔术方法实现**：定义一个 `DataBuffer` 类，内部用一个 list 存储数据。实现 `__len__` 返回数据数量，实现 `__getitem__` 使得对象支持 `buffer[0]` 这样的索引访问。
4. **继承与多态**：写一个基类 `Animal` 带有 `speak()` 方法，子类 `Dog` 和 `Cat` 重写 `speak()` 方法。实例化两者并放入列表，遍历调用 `speak()`。

**任务**：设计一个 `DataProcessor` 基类，定义 `process(data)` 接口；实现一个子类 `NoiseFilter`，通过组合方式接收 `SensorReading` 列表，返回滤波后的列表。

**注意事项**：

- 不要过度设计，不要为了写类而写类。如果只有数据没有方法，直接用 `@dataclass` 或字典即可。
- 严禁在类的外部直接修改类的内部状态，应通过方法操作。

## 概念 3：模块化与代码重构

**学习目标**：将几百行的 `main.py` 脚本重构为可维护、可复用的模块化结构。

**知识点**：

- 单一职责原则
- 配置与代码分离
- 异常处理与日志记录

**子项**：

- **包结构**：`__init__.py` 的作用，相对导入 `from . import xxx` 与绝对导入。
- **拆分原则**：一个 `.py` 文件只做一类事（如 `data_loader.py`, `features.py`, `plotter.py`）。
- **配置分离**：将阈值、窗口大小等参数提取到 `config.yaml` 或使用 `argparse` 传入。
- **日志记录**：使用 `loguru` 库替代 `print`，区分 INFO 和 ERROR 级别，记录到文件。

**练习**：

1. 写一段包含 3 个不同功能函数的“面条代码”（如读取数据、计算均值、画图）。
2. 将其重构：拆分为 3 个独立的 `.py` 文件，并在 `main.py` 中导入调用。
3. 引入 `loguru`，在数据读取成功时打印 INFO，在文件不存在时捕获异常并打印 ERROR。
4. **配置分离实操**：创建一个 `config.json` 文件，写入 `{"threshold": 10, "window_size": 5}`，在 Python 脚本中读取该文件并应用这两个参数。
5. **异常捕获练习**：编写一段代码，尝试打开一个不存在的文件，捕获 `FileNotFoundError`，打印友好提示日志，并创建一个空文件代替。

**任务**：将之前写过的任意一段超过 50 行的科研代码，按照模块化原则进行重构，并确保重构后运行结果一致。

**注意事项**：

- 消除重复代码（DRY原则），相同的逻辑不要复制粘贴三遍。
- 函数长度尽量控制在 50 行以内，超过说明职责不单一。

## 概念 5：NumPy 向量化与张量思维

**学习目标**：掌握向量化计算，彻底理解广播机制与轴的概念，告别低效 for 循环。

**知识点**：

- Ndarray 的创建与属性
- 广播机制
- 轴 与聚合运算
- 矩阵运算与内存视图

**子项**：

- **广播机制（重点）**：规则是从右向左对齐，维度相等或其中一方为 1 即可兼容。如 `(3,1) + (1,3) -> (3,3)`。
- **轴的概念**：`axis=0` 是跨行计算（求每列特征），`axis=1` 是跨列计算（求每行样本）。
- **矩阵运算**：`@` (矩阵乘法), `.T` (转置), `np.dot`。
- **内存视图**：切片创建视图不复制数据，修改切片会影响原数组。

**练习**：

1. 生成一个 10x3 的随机矩阵，计算每列的均值（理解 `axis=0`）。
2. 手动实现一个广播：将形状为 `(3,)` 的行向量与形状为 `(3,1)` 的列向量相加，得到 `(3,3)` 矩阵。
3. **距离计算**：生成 5 个三维点集 A (shape: 5x3) 和 3 个三维点集 B (shape: 3x3)。利用广播机制，计算 A 中每个点到 B 中每个点的欧氏距离，输出 shape 为 5x3 的矩阵（不使用 for 循环）。
4. **视图验证**：创建一个 4x4 的矩阵 `a`，取切片 `b = a[0:2, 0:2]`，修改 `b[0,0] = 999`，打印 `a` 验证 `a` 是否被改变。尝试用 `b = a[0:2, 0:2].copy()` 避免此问题。

**任务**：用 NumPy 生成模拟 IMU 数据（正弦波 + 随机高斯噪声），计算三轴加速度的模长 ∣∣a∣∣=x2+y2+z2∣∣*a*∣∣=*x*2+*y*2+*z*2（全程禁用 for 循环）。

**注意事项**：

- 这是 EE 学生最容易晕的地方，遇到形状不匹配报错，先打印 `array.shape` 检查。
- 不要用双重 `for` 循环遍历 NumPy 数组，速度极慢。如果必须循环，让 AI 帮你改写成向量化代码。

## 概念 9：概率统计与数字滤波

**学习目标**：掌握不确定性建模方法，理解并实现常见滤波器，平滑传感器噪声信号。

**知识点**：

- 概率分布与统计量
- 数字滤波器原理
- 协方差矩阵与状态估计思想

**子项**：

- **高斯分布**：用 `np.random.normal(mean, std)` 生成带噪声数据。
- **协方差矩阵**：用 `np.cov` 计算多变量传感器噪声的相关性。
- **移动平均滤波 (MA)**：通过卷积或滑动窗口实现平滑。
- **低通滤波器**：使用 `scipy.signal.butter` 设计巴特沃斯低通滤波器，并用 `filtfilt` 进行零相位滤波。
- **卡尔曼滤波思想**：理解预测与更新步骤（概念为主，不需手写复杂公式）。

**练习**：

1. 生成一段正弦波，加入高斯噪声。使用 `np.convolve` 实现窗口大小为 5 的移动平均滤波，并画出前后对比图。
2. **协方差计算**：生成两组相关的随机数据（如温度和功耗），计算其协方差矩阵并解释含义。
3. **巴特沃斯滤波**：使用 `scipy.signal` 设计一个截止频率为 10Hz 的低通滤波器，对含有高频噪声的 100Hz 采样信号进行滤波，观察波形变化。

**任务**：读取一份真实的 IMU 电流传感器数据，分别使用移动平均和巴特沃斯低通滤波器处理信号，在一个 2x1 子图中分别画出两种滤波后的结果与原始信号的对比。

**注意事项**：

- 移动平均会引入信号延迟，如果要避免延迟，应使用 `scipy.signal.filtfilt`（前向加反向滤波）。
- 滤波器设计需要根据实际采样率调整参数，不要盲目套用。
