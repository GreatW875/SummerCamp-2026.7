## 1. 项目背景与意义

### 1.1 研究背景

步态分析（Gait Analysis）是研究人体行走方式的一门科学，广泛应用于临床诊断、运动康复、人体工效学及智能监控等领域。传统的步态分析依赖于昂贵的实验室设备，如三维动作捕捉系统（Vicon）、测力台和高速摄像机等，这些设备成本高昂（通常数十万至数百万元）、部署复杂、使用场景受限，难以实现日常化的运动监测。

随着智能手机和可穿戴设备的普及，内置的惯性测量单元（IMU）和全球导航卫星系统（GNSS）为低成本、便携式的步态分析提供了新的技术路径。智能手机的加速度计和陀螺仪采样率可达 100-500 Hz，足以捕捉人体运动的细微特征。同时，多模态大模型和机器学习技术的发展，使得基于传感器数据的自动运动识别成为可能。

### 1.2 现有方案局限性

| 方案类型                   | 优点                 | 局限性                             |
| :------------------------- | :------------------- | :--------------------------------- |
| 实验室动作捕捉             | 精度极高（亚毫米级） | 成本极高、环境受限、无法日常使用   |
| 专用可穿戴设备（如 Xsens） | 精度较高、便携       | 价格昂贵（数万元）、需专业操作     |
| 简单计步 App               | 成本低、易获取       | 仅计数步数，无步态分析、无运动分类 |
| 基于视频的步态分析         | 非接触式             | 受光照和遮挡影响大、隐私问题       |

### 1.3 本项目创新点

1. **低成本大众化**：仅利用智能手机或智能手表，无需额外硬件投入。
2. **多模态数据融合**：结合 IMU、GNSS 和可选视频数据，提升识别鲁棒性。
3. **端到端系统**：从数据采集、处理、模型训练到实时 Web 可视化，形成完整闭环。
4. **实时交互**：通过 WebSocket 实现低延迟的数据传输与展示。

本实验旨在构建一个端到端的运动数据分析与展示系统，具体目标如下：

## 3. 研究内容

### 3.1 数据采集

#### 3.1.1 采集设备与传感器

- **设备**：小米 14 Pro（Android 14）+ Apple Watch Series 9（辅助验证）
- **IMU 传感器**：
  - 三轴加速度计（Accelerometer）：测量线性加速度，单位 m/s²
  - 三轴陀螺仪（Gyroscope）：测量角速度，单位 rad/s
  - 采样率：100 Hz（即每 10ms 一个样本）
- **GNSS**：GPS + 北斗双模定位，记录经纬度坐标
- **摄像头**：后置主摄，录制 1080p@30fps 视频，用于辅助标注和数据验证

#### 3.1.2 运动类型定义







| 运动类型             | 定义                      | 关键特征                              |
| :------------------- | :------------------------ | :------------------------------------ |
| 走路（Walking）      | 自然行走，速度约 3-5 km/h | 步频低、加速度变化平缓、周期性明显    |
| 跑步（Running）      | 慢跑或快跑，速度 > 8 km/h | 步频高、垂直加速度峰值大、冲击明显    |
| 跳跃（Jumping）      | 原地连续纵跳              | 非周期性、垂直加速度极大、空中 phases |
| 高抬腿（High Knees） | 原地高抬腿跑              | 高频、大腿抬升高度大、垂直位移显著    |

#### 3.1.3 采集流程

1. 将手机固定于腰部右侧（使用运动臂包），确保传感器坐标系与人体运动方向一致。
2. 打开 SensorLog App（或自研采集 App），设置采样率为 100 Hz。
3. 每种运动持续采集 3 分钟，中间休息 1 分钟，每种运动采集 10 组，共 40 组数据。
4. 同步记录 GNSS 轨迹（适用于走路和跑步）。
5. 使用摄像头录制侧面视频，便于后期人工标注验证。

### 3.2 数据预处理与特征工程

#### 3.2.1 数据清洗

Python



```python
import pandas as pd
import numpy as np
from scipy import signal

# 1. 加载数据
df = pd.read_csv('raw_sensor_data.csv')

# 2. 处理缺失值：使用线性插值
df = df.interpolate(method='linear')

# 3. 去除异常值：使用 3σ 原则
for col in ['acc_x', 'acc_y', 'acc_z', 'gyro_x', 'gyro_y', 'gyro_z']:
    mean, std = df[col].mean(), df[col].std()
    df = df[(df[col] >= mean - 3*std) & (df[col] <= mean + 3*std)]

# 4. 传感器校准：去除重力分量（高通滤波）
# 重力加速度约 9.8 m/s²，主要在 Z 轴
# 使用高通滤波器去除直流分量（重力）
sos = signal.butter(4, 0.5, btype='high', fs=100, output='sos')
df['acc_z_filtered'] = signal.sosfilt(sos, df['acc_z'])
```

**关键说明**：加速度计同时测量运动加速度和重力加速度。为分离运动加速度，采用高通滤波（截止频率 0.5 Hz）去除重力分量。陀螺仪数据无需此处理，因为角速度不受重力影响。

#### 3.2.2 滤波处理

采用 **巴特沃斯带通滤波器**（Butterworth Bandpass Filter），保留人体运动的主要频率范围（0.5-20 Hz）：

Python



```python
def butter_bandpass_filter(data, lowcut=0.5, highcut=20, fs=100, order=4):
    """
    巴特沃斯带通滤波器
    
    参数:
        data: 输入信号
        lowcut: 低频截止 (Hz)
        highcut: 高频截止 (Hz)
        fs: 采样率 (Hz)
        order: 滤波器阶数
    """
    nyq = 0.5 * fs  # 奈奎斯特频率
    low = lowcut / nyq
    high = highcut / nyq
    sos = signal.butter(order, [low, high], btype='band', output='sos')
    return signal.sosfilt(sos, data)

# 对加速度各轴应用带通滤波
acc_cols = ['acc_x', 'acc_y', 'acc_z']
for col in acc_cols:
    df[f'{col}_filtered'] = butter_bandpass_filter(df[col].values)
```

**滤波效果分析**：人体步态运动的频率范围通常在 0.5-12 Hz 之间。低于 0.5 Hz 的成分主要来自身体姿态变化和重力；高于 20 Hz 的成分多为高频噪声。带通滤波有效保留了步态特征，同时抑制了噪声。

#### 3.2.3 特征提取

采用滑动窗口法（Windowing），窗口大小 2 秒（200 个样本），步长 0.5 秒（50 个样本）：

**时域特征**：

Python



```python
def extract_time_features(window):
    """从时域窗口提取特征"""
    features = {}
    
    # 基本统计特征
    features['mean_x'] = np.mean(window['acc_x'])
    features['mean_y'] = np.mean(window['acc_y'])
    features['mean_z'] = np.mean(window['acc_z'])
    features['std_x'] = np.std(window['acc_x'])
    features['std_y'] = np.std(window['acc_y'])
    features['std_z'] = np.std(window['acc_z'])
    
    # 峰值特征
    features['max_x'] = np.max(window['acc_x'])
    features['max_y'] = np.max(window['acc_y'])
    features['max_z'] = np.max(window['acc_z'])
    
    # 过零率（Zero Crossing Rate）
    features['zcr_x'] = np.sum(np.diff(np.sign(window['acc_x'])) != 0) / len(window)
    
    # 步频估计：通过加速度 Z 轴峰值检测
    peaks, _ = signal.find_peaks(window['acc_z'], height=2, distance=20)
    features['step_freq'] = len(peaks) / 2.0  # 2秒窗口内的步数/2 = 步频(Hz)
    
    # 合成加速度幅值（Magnitude）
    mag = np.sqrt(window['acc_x']**2 + window['acc_y']**2 + window['acc_z']**2)
    features['mag_mean'] = np.mean(mag)
    features['mag_std'] = np.std(mag)
    features['mag_max'] = np.max(mag)
    
    # 相关系数（轴间相关性）
    features['corr_xy'] = np.corrcoef(window['acc_x'], window['acc_y'])[0,1]
    features['corr_xz'] = np.corrcoef(window['acc_x'], window['acc_z'])[0,1]
    
    return features
```

**频域特征**（基于 FFT）：

Python



```python
def extract_freq_features(window, fs=100):
    """从频域提取特征"""
    features = {}
    
    # 对 Z 轴加速度做 FFT
    fft_vals = np.fft.rfft(window['acc_z'])
    fft_freq = np.fft.rfftfreq(len(window), 1/fs)
    fft_power = np.abs(fft_vals)**2
    
    # 主频率（功率谱峰值对应的频率）
    dominant_freq_idx = np.argmax(fft_power[1:]) + 1  # 排除直流分量
    features['dominant_freq'] = fft_freq[dominant_freq_idx]
    
    # 频谱能量分布
    features['spectral_energy'] = np.sum(fft_power)
    features['spectral_entropy'] = -np.sum((fft_power/np.sum(fft_power)) * np.log2(fft_power/np.sum(fft_power) + 1e-10))
    
    # 频带能量比（低频 vs 高频）
    low_band = (fft_freq >= 0.5) & (fft_freq <= 3)
    high_band = (fft_freq > 3) & (fft_freq <= 10)
    features['low_high_energy_ratio'] = np.sum(fft_power[low_band]) / (np.sum(fft_power[high_band]) + 1e-10)
    
    return features
```

df['lat_smooth'] = df['lat'].rolling(window=5, center=True).mean()

# 计算相邻点距离（Haversine 公式）
from math import radians, cos, sin, asin, sqrt

def haversine(lon1, lat1, lon2, lat2):
    """计算两点间距离（米）"""
    lon1, lat1, lon2, lat2 = map(radians, [lon1, lat1, lon2, lat2])
    dlon = lon2 - lon1
    dlat = lat2 - lat1
    a = sin(dlat/2)**2 + cos(lat1) * cos(lat2) * sin(dlon/2)**2
    return 2 * 6371 * 1000 * asin(sqrt(a))  # 返回米

# 计算瞬时速度
df['distance'] = 0.0
for i in range(1, len(df)):
    df.loc[i, 'distance'] = haversine(df.loc[i-1, 'lon'], df.loc[i-1, 'lat'],
                                       df.loc[i, 'lon'], df.loc[i, 'lat'])
df['speed'] = df['distance'] / 0.1  # 100Hz = 0.1s 间隔

import matplotlib.pyplot as plt

def plot_sensor_data(df, start=0, end=1000, save_path=None):

    绘制三轴加速度与陀螺仪波形图
    
    参数:
        df: 包含传感器数据的 DataFrame
        start, end: 绘制的时间范围（样本索引）
        save_path: 保存路径

    fig, axes = plt.subplots(2, 1, figsize=(14, 8), sharex=True)
    
    time = np.arange(start, end) / 100.0  # 转换为秒
    
    # 加速度
    axes[0].plot(time, df['acc_x'][start:end], label='X', color='r', alpha=0.8)
    axes[0].plot(time, df['acc_y'][start:end], label='Y', color='g', alpha=0.8)
    axes[0].plot(time, df['acc_z'][start:end], label='Z', color='b', alpha=0.8)

app = Flask(__name__)
app.config['SECRET_KEY'] = 'gait-analysis-secret'
socketio = SocketIO(app, cors_allowed_origins="*")

# 加载预训练模型和标准化器
rf_model = joblib.load('models/rf_model.pkl')
scaler = joblib.load('models/scaler.pkl')

# 滑动窗口缓冲区（存储最近 2 秒的数据）
WINDOW_SIZE = 200
sensor_buffer = []

@app.route('/')
def index():
    """渲染主页"""
    return render_template('index.html')

@socketio.on('connect')
def handle_connect():
    print('Client connected')
    emit('response', {'data': 'Connected to Gait Analysis Server'})

@socketio.on('sensor_data')
def handle_sensor_data(data):
    """
    接收来自手机端的传感器数据
    
    参数 data 格式:
    {
        'timestamp': 1719820800000,
        'acc_x': 0.12, 'acc_y': 0.05, 'acc_z': 9.81,
        'gyro_x': 0.01, 'gyro_y': -0.02, 'gyro_z': 0.00,
        'lat': 39.9042, 'lon': 116.4074
    }
    """
    global sensor_buffer
    
    # 添加到缓冲区
    sensor_buffer.append([
        data['acc_x'], data['acc_y'], data['acc_z'],
        data['gyro_x'], data['gyro_y'], data['gyro_z']
    ])
    
    # 保持窗口大小
    if len(sensor_buffer) > WINDOW_SIZE:
        sensor_buffer.pop(0)
    
    # 当缓冲区满时进行预测
    if len(sensor_buffer) == WINDOW_SIZE:
        # 提取特征
        window = np.array(sensor_buffer)
        features = extract_features_realtime(window)  # 实时特征提取函数
        
        # 标准化并预测
        features_scaled = scaler.transform([features])
        prediction = rf_model.predict(features_scaled)[0]
        proba = rf_model.predict_proba(features_scaled)[0]
        
        # 计算步频
        step_freq = calculate_step_freq(window)
        
        # 发送结果回前端
        result = {
            'motion_type': prediction,
            'confidence': float(np.max(proba)),
            'probabilities': {
                'walking': float(proba[0]),
                'running': float(proba[1]),
                'jumping': float(proba[2]),
                'high_knees': float(proba[3])
            },
            'step_freq': step_freq,
            'timestamp': data['timestamp'],
            'lat': data['lat'],
            'lon': data['lon']
        }
        emit('prediction_result', result)
    
    # 同时转发原始数据用于实时绘图
    emit('sensor_update', data)

def extract_features_realtime(window):
    """实时特征提取（简化版，针对 200 样本窗口）"""
    features = []
    
    # 加速度统计特征
    for i in range(3):
        features.extend([
            np.mean(window[:, i]),
            np.std(window[:, i]),
            np.max(window[:, i]),
            np.min(window[:, i])
        ])
    
    # 陀螺仪统计特征
    for i in range(3, 6):
        features.extend([
            np.mean(window[:, i]),
            np.std(window[:, i])
        ])
    
    # 合成加速度幅值
    mag = np.sqrt(np.sum(window[:, :3]**2, axis=1))
    features.extend([np.mean(mag), np.std(mag), np.max(mag)])
    
    return features

def calculate_step_freq(window):
    """实时步频计算"""
    from scipy.signal import find_peaks
    mag = np.sqrt(np.sum(window[:, :3]**2, axis=1))
    peaks, _ = find_peaks(mag, height=np.mean(mag), distance=20)
    return len(peaks) / 2.0  # 2秒窗口

@socketio.on('disconnect')
def handle_disconnect():
    print('Client disconnected')

if __name__ == '__main__':
    socketio.run(app, host='0.0.0.0', port=5000, debug=True)

# mobile_client.py - 手机端数据发送脚本（需在手机上运行）
import socketio
import time
import json
from plyer import accelerometer, gyroscope, gps  # Kivy 的传感器接口

sio = socketio.Client()

@sio.event
def connect():
    print('Connected to server')

def send_sensor_data():
    """读取传感器数据并发送到服务器"""
    while True:
        try:
            # 读取加速度（单位：m/s²）
            acc = accelerometer.acceleration  # 返回 (x, y, z)
            
            # 读取陀螺仪（单位：rad/s）
            gyro = gyroscope.rotation  # 返回 (x, y, z)
            
            # 读取 GPS
            gps_data = gps.get_location()
            
            data = {
                'timestamp': int(time.time() * 1000),
                'acc_x': acc[0], 'acc_y': acc[1], 'acc_z': acc[2],
                'gyro_x': gyro[0], 'gyro_y': gyro[1], 'gyro_z': gyro[2],
                'lat': gps_data.get('lat', 0),
                'lon': gps_data.get('lon', 0)
            }
            
            sio.emit('sensor_data', data)
            time.sleep(0.01)  # 100 Hz
            
        except Exception as e:
            print(f"Error: {e}")
            time.sleep(0.1)

if __name__ == '__main__':
    sio.connect('http://YOUR_SERVER_IP:5000')
    send_sensor_data()

### 5.2 数据采集过程

**遇到的问题**：手机传感器坐标系与人体坐标系不一致。

**解决方案**：统一将手机固定于腰部右侧，屏幕朝外，顶部朝上。此时：

- 手机 X 轴 ≈ 人体左右方向
- 手机 Y 轴 ≈ 人体前后方向
- 手机 Z 轴 ≈ 人体垂直方向

### 5.3 数据预处理难点

**难点 1：重力分量分离**

- 加速度计同时测量运动加速度和重力加速度。
- 解决方案：使用高通滤波（截止频率 0.5 Hz）去除重力分量，保留运动加速度。

**难点 2：不同设备采样率不一致**

- 部分手机实际采样率低于设置的 100 Hz。
- 解决方案：采集后使用线性插值重采样到统一频率。
