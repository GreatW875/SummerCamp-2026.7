## 1. 项目背景与意义

探索利用大众化设备实现低成本、便携式的步态分析与运动轨迹追踪，通过数据挖掘与机器学习技术，实现运动的自动识别，并构建一个实时可视化的网页应用，为个人运动指导和科研分析提供支持。

## 2. 实验目的

本实验的核心目标是构建一个端到端的运动数据分析与展示系统，具体目的包括：

1. **数据采集与构建数据集：** 通过智能手机或智能手表采集跑步、走路、跳跃、高抬腿等四种典型运动的原始传感器数据（IMU+GNSS，辅以摄像头图像信息）。
2. **步态特征提取与分类：** 对采集的原始数据进行预处理和特征提取，训练机器学习模型，实现对不同运动类型的高精度自动识别与分类。
3. **数据分析与可视化：** 利用 Python 的 Matplotlib 库对分析结果进行静态或动态可视化，包括步态周期图、传感器数据波形图等。
4. **构建实时Web应用：** 开发一个基于电脑端的网页应用，能够实时接收、解析并展示运动数据、识别出的步态类型以及用户的运动轨迹。

## 3. 研究内容

### 3.1 数据采集

- **设备：** 智能手机或智能手表。
- **传感器：**
  - **IMU (Inertial Measurement Unit)：** 包含三轴加速度计和三轴陀螺仪，用于捕获身体的运动加速度和角速度，是步态分析的核心数据。
  - **GNSS (Global Navigation Satellite System)：** 用于记录用户的地理位置信息，用于绘制运动轨迹。
  - **摄像头 (可选)：** 用于记录运动过程中的视频片段，作为辅助验证或用于基于计算机视觉的补充分析。
- **运动类型：**
  - 走路
  - 跑步
  - 跳跃
  - 高抬腿
- **数据记录：** 同步记录各传感器的原始数据流，并确保时间戳对齐。

### 3.2 数据预处理与特征工程

- **数据清洗：** 去除噪声、处理缺失值、进行传感器校准。
- **滤波：** 采用低通、高通或带通滤波器（如巴特沃斯滤波）去除信号中的高频噪声和重力分量。
- **特征提取：** 从时域和频域提取关键特征，例如：
  - 时域：均值、方差、峰值、过零率、步频、步长等。
  - 频域：快速傅里叶变换（FFT）后的主要频率成分、能量分布等。
- **轨迹数据处理：** 对 GNSS 坐标数据进行平滑处理，计算距离、速度等。

### 3.3 运动识别与分类模型构建

- **模型选择：** 尝试使用传统的机器学习算法（如支持向量机 SVM、随机森林 Random Forest）或深度学习模型（如卷积神经网络 CNN、循环神经网络 RNN/LSTM）。
- **模型训练与评估：** 将数据集划分为训练集和测试集，对模型进行训练和参数调优，使用准确率、精确率、召回率和 F1 分数等指标评估模型性能。

### 3.4 数据可视化 (基于 Matplotlib)

- **传感器数据可视化：** 绘制三轴加速度、三轴角速度随时间变化的波形图。
- **步态特征可视化：** 绘制不同运动类型的特征分布图、混淆矩阵等。
- **轨迹可视化：** 在二维平面上绘制用户的运动路径。

### 3.5 实时网页应用开发

- **后端：** 使用 Python 的 Web 框架（如 Flask 或 Django）搭建服务器，负责接收来自手机/手表的实时数据流，并调用训练好的分类模型进行实时推断。
- **前端：** 使用 HTML、CSS 和 JavaScript 构建用户界面。
- **实时通信：** 利用 WebSocket 技术实现服务器与浏览器之间的双向、实时数据传输。
- **可视化展示：**
  - 实时显示当前的运动类型（如：跑步）。
  - 动态绘制传感器数据曲线。
  - 在地图（如 OpenStreetMap 或百度地图）上实时更新用户的运动轨迹。
  - 显示关键步态参数（如：当前步频、速度）。

## 5. 预期成果

1. **构建一个多模态运动数据集：** 包含走路、跑步、跳跃、高抬腿四种运动的 IMU、GNSS 及视频数据。
2. **一个高精度的步态识别模型：** 能够准确分类上述四种运动类型。
3. **一个功能完备的实时网页应用：** 具备数据接收、实时步态识别、轨迹追踪和数据可视化功能。
